# Orchestration security invariants

1. [FastAPI Context](../../apps/api/src/insightrag/security/dependencies.py) validates the bearer token, resolves a provisioned identity and checks current organization membership. The caller's header selects a candidate organization; it does not establish membership or resource access.
2. [OrchestrationRequest](../../apps/api/src/insightrag/orchestration/contracts.py) validates shape, not permissions. The graph does not mutate source IDs or infer extra IDs from prompt text.
3. [Phase 5 retrieval](../../apps/api/src/insightrag/retrieval/service.py) checks workspace and document ACLs before retrieval and revalidates evidence/citations before release. Retrieved text remains untrusted data.
4. [Phase 6 analytics](../../apps/api/src/insightrag/analytics/service.py) checks current dataset `query` grant, active version, row entitlement and workspace match in its transaction. Only fixed SQL templates reach PostgreSQL. The graph never runs raw generated SQL.
5. [Graph verification](../../apps/api/src/insightrag/orchestration/graph.py) refuses missing or unsupported service statuses. Authorization failures propagate; a provider 503/504 can make a hybrid response partial only after analytics has returned its verified result. No document snippet is invented on that path.
6. Chart points are copied from [AnalyticsResponse](../../apps/api/src/insightrag/analytics/contracts.py) decimal strings. Document narrative is displayed separately from exact figures; the graph does not infer causality from their co-occurrence.
7. No checkpoint or graph cache stores evidence. Conversation history remains inside Phase 5 with its owner and permission rechecks. Structured logs omit raw questions, excerpts and SQL values.

Threats: prompt injection in a document cannot change graph edges or tool arguments because routing is deterministic and the Phase 5 service treats content as evidence. A forged dataset/workspace combination fails the analytics transaction's workspace comparison. A stale or revoked grant fails inside the underlying service. A malicious hybrid subquestion may be rejected by the Phase 6 bounded planner or Phase 5 normalizer. There is no claim that prompt wording alone prevents every hallucination; Phase 5 citation verification and human review of causal statements remain necessary.

Regression evidence lives in [test_orchestration.py](../../apps/api/tests/test_orchestration.py) (no unauthorized fallback, no tool call on clarification, provider partial path, timeout) and [test_rls_integration.py](../../apps/api/tests/test_rls_integration.py) (workspace mismatch under real PostgreSQL). Remaining production controls: TLS termination, OIDC provider setup, authorized provider egress, OTel exporter access control, request rate limits, and independent load/security testing. No compliance certification is asserted.
