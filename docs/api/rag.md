# Versioned RAG API contract

`POST /api/v1/rag/query` is a bounded REST request/response endpoint. It requires the existing bearer OIDC token and `X-Organization-ID`; the header selects a scope but does not authorize it. Body: `workspace_id` UUID, `question` string, optional `resource_ids` UUID array (max 32), optional `conversation_id` UUID, optional `use_mmr` boolean, and optional `max_context_tokens`/`max_completion_tokens`. The per-request token fields can only lower the server's configured retrieval and generation caps; they are not a dollar-cost guarantee. Empty `resource_ids` selects only currently readable active documents in the requested workspace. The route is implemented in [retrieval/routes.py](../../apps/api/src/insightrag/retrieval/routes.py); Pydantic types are in [retrieval/contracts.py](../../apps/api/src/insightrag/retrieval/contracts.py).

Response: `status` is `answered`, `abstained` or `analytics_required`; `answer`, optional `uncertainty`, `conversation_id`, `citations`, and optional provider `prompt_tokens`/`completion_tokens`. Each citation has opaque `id`, `resource_id`, `workspace_id`, document title, immutable `version_id`/number, source `locator`, chunk position and exact excerpt. Internal object-store paths are absent. A citation is not a read capability. The response is finalized only after post-generation ACL/version checks.

Errors use existing structured security error contracts: 401 authentication; 404 inaccessible workspace/document/conversation; 409 changed policy or evidence; 422 invalid query; 429 rate limit; 502 invalid generated citation; 503 unconfigured/unavailable embedding or generation provider. A reranker failure falls back to fused rank and is not exposed as 503. No streaming endpoint exists in this phase. OpenAPI is available at `/docs` outside production.
