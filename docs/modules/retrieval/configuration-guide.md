# Retrieval configuration and operations

The environment prefix is `INSIGHTRAG_`; secret values can be mounted as `*_FILE`. See root `.env.example` and `core/config.py`. The embedding endpoint/key/model must match Phase 4 active `document_versions.model_id`, and the vector column is fixed at 1,536 dimensions. The generation endpoint/key/model must support an HTTPS OpenAI-compatible chat-completions JSON-object response, `max_completion_tokens` and `store=false`. `INSIGHTRAG_GENERATION_TEMPERATURE` is optional because some models restrict that parameter; `INSIGHTRAG_GENERATION_MAX_COMPLETION_TOKENS` defaults to 800. Unconfigured providers fail with 503 for document answers. The optional reranker endpoint/key/model must accept `{model,query,documents}` and return `{scores:[finite numbers]}` in candidate order. This is a project adapter contract, not a generic provider standard.

Defaults: dense/sparse candidate pools 20 each, fusion pool 20, context chunks 6, evidence context budget 2,400 `cl100k_base` tokens, rerank pool 12, RRF constant 60, MMR off, no cosine-distance cutoff. The service limits requests through the existing per-user and per-organization limiter. A cosine cutoff can be configured with `INSIGHTRAG_RETRIEVAL_MAX_COSINE_DISTANCE` only after measuring relevant/irrelevant distance distributions for the exact embedding model. Higher cosine distance is worse; raw `ts_rank_cd` values are on another scale. MMR currently uses λ=0.7 when the request enables it. Treat these as initial operational bounds, not optimized values.

Migrate with `uv run --locked --no-sync alembic -c apps/api/alembic.ini upgrade head`. Check `/health/ready` for migration `0006_retrieval` and metadata `phase5`. A migration rollback removes conversation history, so back up and follow the database runbook before downgrade. Run the offline evaluation with `uv run --locked --no-sync python scripts/evaluate-retrieval.py`. For a live HTTP query, provision a real OIDC principal/member/workspace/read grant, publish a document under the same embedding model, then call `POST /api/v1/rag/query` with bearer token and `X-Organization-ID`; use the OpenAPI schema at `/docs` in nonproduction environments.

Operational triage: 404 for inaccessible workspace/resource/conversation; 409 for policy or evidence change; 422 for malformed query; 502 for invalid citation; 503 for missing embedding/generation provider. A missing result abstains. Inspect request IDs, candidate counts, citation failures and stage timing, never private text in default logs. If a model profile changes, reindex the document via Phase 4 and publish before querying; mixed versions are intentionally excluded. Retention of `rag_turns` needs a tenant policy and deletion job before production use.
