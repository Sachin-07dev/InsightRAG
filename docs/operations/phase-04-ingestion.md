# Phase 4 ingestion operations

Apply migrations before API/worker startup: `uv run alembic -c apps/api/alembic.ini upgrade head`; expected revision is `0005_reindex`. The root [runbook](../../README.md) covers local Compose. The existing Phase 3 OIDC, ClamAV, Redis, signed-job key, restricted runtime DB role and TLS controls remain prerequisites. Configure a private S3-compatible bucket, regional endpoint and managed KMS key with environment variables `INSIGHTRAG_OBJECT_BUCKET`, `INSIGHTRAG_OBJECT_REGION`, `INSIGHTRAG_OBJECT_KMS_KEY_ID`, optionally `INSIGHTRAG_OBJECT_ENDPOINT` (HTTPS only). Configure `INSIGHTRAG_EMBEDDING_ENDPOINT` (HTTPS), `INSIGHTRAG_EMBEDDING_API_KEY_FILE` and `INSIGHTRAG_EMBEDDING_MODEL`; the provider must return 1536D embeddings. Set `INSIGHTRAG_INGESTION_OCR_ENABLED=true` only after Tesseract is installed and scanned-page quality is measured. Secrets belong in secret mounts, not `.env` committed to git.

The local Compose file does **not** provision S3/KMS, ClamAV, Tesseract or a hosted embedding provider. Without them, upload remains unavailable by design. This separation prevents a local fake from being mistaken for a production integration. A test deployment needs actual private object/scan/provider services or explicit local test doubles, with separate credentials and bucket policy.

Monitor API upload bytes/rejections, scanner outages, S3 error rate, broker publish errors, queued/running age, stage durations, retries, parse/OCR quality, embedding 429 and token/cost, HNSW build/index size, stale publication count, object orphan count and deletion pending age. An operator should investigate an old queued job, verify current policy and object hash, then use `python -m insightrag.ingestion.dispatch --organization-id UUID --actor-id UUID --job-id UUID`. Do not redispatch a job after policy revision changes; create a new authorized version. Deletion jobs use the existing signed security dispatch path. Missing storage leaves `pending_storage`; legal hold/retention leaves `held`.

Reliability gaps: there is no automated outbox dispatcher, stuck-running sweeper, orphan object collector, dedicated OCR queue, parser sandbox or provider rate budget. The 50 MiB source limit and 270-second worker hard limit bound one attempt; large or adversarial documents can still expand beyond source size. Add these controls before declaring production readiness. Verify storage deletion receipts, replicas and backups against regional retention policy. See [security](../security/ingestion-security.md), [tests](../testing/ingestion-tests.md), and [architecture](../modules/ingestion/architecture.md).
