# Embeddings, similarity and pgvector

An embedding maps text (x) to a real vector (e(x)\in\mathbb{R}^{1536}). Nearby vectors may encode similar meaning, but proximity is neither a citation nor a numerical computation. [The provider](../../apps/api/src/insightrag/ingestion/embeddings.py) sends bounded HTTPS batches to an operator-configured endpoint and rejects missing, nonfinite, zero or wrong-dimension outputs. [The schema](../../apps/api/migrations/versions/0003_ingestion.py) stores `vector(1536)` with tenant/resource/version/locator metadata and an HNSW cosine index. Current code stages vectors; Phase 5 will implement retrieval and measure its quality.

For vectors (a,b), cosine similarity is ((a\cdot b)/(||a||_2||b||_2)), dot product is (Σ_i a_i b_i), and Euclidean distance is (√(Σ_i(a_i-b_i)^2)). If both are unit-normalized, cosine equals dot product, and squared Euclidean distance is (2-2\cos(a,b)). Example: (a=(1,0)), (b=(0.8,0.6)): both unit vectors, cosine/dot = 0.8, Euclidean distance (√0.4\approx0.632). Without normalization, dot product also reflects magnitude. pgvector's `<=>` operator is cosine distance; a future authorized query can order by it after RLS/metadata filtering. Exact nearest neighbor checks every eligible vector and is a recall reference. HNSW navigates a layered neighbor graph approximately, improving latency at index-build/RAM cost; it can miss a true neighbor. Tune `ef_search` and filtering on real corpora, reporting recall@k versus p95 latency. A tenant/resource filter must still be applied even with RLS.

Batching amortizes network overhead but makes a failed batch retry together; respect provider rate limits and cost. Model changes can alter vector space even when dimensions stay 1536. Record `model_id`, build a new version/index profile, reembed and compare results before switching. Do not compare scores across incompatible models. FAISS is useful for embedded or offline nearest-neighbor experiments but lacks PostgreSQL transaction/RLS integration; a dedicated vector DB becomes reasonable only if measured scale/latency warrants the consistency boundary.
