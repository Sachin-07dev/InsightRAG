# Tokens, structure-aware chunks and overlap

A token is a unit in a model vocabulary, not necessarily a word: punctuation, common subwords and spaces can each map differently. Tokenization maps text to integer IDs; embedding providers impose input-token limits and cost often scales with tokens. [The chunker](../../apps/api/src/insightrag/ingestion/chunking.py) uses a pinned offline `cl100k_base` BPE table (SHA-256 verified at setup) and windows of at most 512 IDs with 48 IDs overlap. The stride is `512−48=464`. For a 1,000-token segment, starts are 0, 464 and 928; the first two windows overlap by 48, while the final window contains the tail. Each window keeps its true PDF page/block, DOCX body/table, or TXT line locator and current heading. Distinct source segments are not merged, so a citation does not accidentally span pages.

Fixed character chunks are simple but ignore token budgets. Recursive splitting uses separators and often preserves sentences; semantic splitting uses embedding similarity and costs additional inference. Structure-aware splitting respects headings, tables and pages but requires reliable extraction. The current approach preserves segment boundaries but can split a sentence or table internally, and BPE decoding at a window boundary may not reproduce byte-for-byte text. Overlap can improve recall around boundaries but duplicates storage and embedding cost; measure labeled question recall, answer faithfulness, locator accuracy, context precision and latency before tuning. A model whose tokenizer differs from cl100k requires a versioned token profile and re-chunking. Never assume a 512-token chunk is safe for every embedding model.

The source artifact is packaged under [tokenizer assets](../../apps/api/src/insightrag/ingestion/assets); first-use workers do not need outbound access. The encoding is distinct from an embedding model: token IDs are discrete symbols, whereas an embedding is a floating-point vector. Interview defense: choose chunk size by the model limit and retrieval evaluation, not a universal rule; use overlap only when measured boundary misses justify its cost.
