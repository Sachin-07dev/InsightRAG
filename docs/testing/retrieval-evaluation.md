# Phase 5 tests and reproducible evaluation

## Executed checks

The Phase 5 isolated real-service run used the existing Docker PostgreSQL/Redis test stack with Alembic `0006_retrieval`. The targeted real PostgreSQL test `pytest -q apps/api/tests/test_rls_integration.py -k phase5 -m integration` passed **2 tests**: authorized dense/FTS retrieval, cross-tenant/document restriction and deleted exclusion; then grounded answer, real version citation, owner-scoped conversation continuation, foreign conversation denial, mid-inference grant revocation, and checking stored turns contain no generated answer or source excerpt. `pytest -q apps/api/tests/test_retrieval.py` passed **6 tests** for normalization, RRF, MMR, token budget/citations, ranking metrics and the chat-adapter request/error contract. The final full unit/non-integration suite passed **220 tests**; the full real-service integration suite passed **57 tests** after the data-minimization adjustment. Ruff lint and format checks passed; `mypy apps/api/src` passed on 47 source files. These are synthetic tests, not production assurance.

The real Uvicorn HTTP smoke passed. `npm run check:docs` passed 11 documentation consistency checks after its Mermaid recognizer was updated for existing `flowchart TD` and `stateDiagram-v2` syntax; this is not visual Mermaid rendering or security assurance.

`uv run --locked --no-sync python scripts/evaluate-retrieval.py` ran the deterministic **four-case synthetic ranking** fixture `apps/api/tests/fixtures/rag_rankings.json`. Output from this execution:

| Channel | MRR | Recall@3 | NDCG@3 | Local ranking ms |
| --- | ---: | ---: | ---: | ---: |
| Dense supplied ranks | 0.6250 | 0.7500 | 0.6377 | 0.835 |
| Sparse supplied ranks | 0.5833 | 0.7500 | 0.6250 | 0.222 |
| RRF of supplied ranks | 0.6250 | 0.7500 | 0.6577 | 123.649 |

These rankings were supplied in a toy JSON fixture, not generated by pgvector, PostgreSQL FTS, an embedding model or a reranker. The 123.649 ms includes Python object/UUID construction on one run and is **not** a query latency estimate. The tiny fixture does not establish a statistically meaningful hybrid improvement or configuration optimum. Do not deploy a threshold or reranker based on it.

## Reproduction

From repository root set `UV_CACHE_DIR` to a writable local directory if required. Run `uv run --locked --no-sync pytest -q apps/api/tests -m 'not integration'`, `uv run --locked --no-sync ruff check .`, `uv run --locked --no-sync ruff format --check .`, `uv run --locked --no-sync mypy apps/api/src`, and `uv run --locked --no-sync python scripts/evaluate-retrieval.py`. For real-service tests, start the isolated PostgreSQL/Redis Compose stack, set `INSIGHTRAG_TEST_DATABASE_URL_FILE`, `INSIGHTRAG_TEST_MIGRATION_DATABASE_URL_FILE`, `INSIGHTRAG_TEST_REDIS_URL_FILE` to local secret files, run `uv run --locked --no-sync alembic -c apps/api/alembic.ini upgrade head`, then `uv run --locked --no-sync pytest -q apps/api/tests -m integration`. The fixture refuses to substitute SQLite or a DB-owner role for runtime isolation tests.

## Evaluation plan and unverified work

Build a larger labelled, synthetic permission-aware set with factual, semantic, exact-ID, multi-document, conflicting, unanswerable, restricted, deleted, updated, injection, numerical-handoff and follow-up cases. Split by document/topic so near-duplicate chunks do not leak into test labels. Record corpus/chunk/embedding/reranker/generator versions, vector dimension, index configuration, SQL plans and software versions. Compare dense, sparse, hybrid, rerank, K, thresholds, MMR, context order, rewrite, chunking, exact versus ANN and model choices one variable at a time. Report P/R/Hit@K, MRR, MAP, NDCG, candidate coverage, exact-search ANN recall, answer correctness, faithfulness, citation accuracy/coverage, abstention, hallucination, permission compliance, p50/p95/p99 end-to-end and stage latency, token usage and estimated cost with an explicit price source. Use human adjudication on disputed answers; LLM-as-judge can share hallucination and prompt biases. These provider-backed and load experiments have **not** been executed, so there are no claimed quality lifts, p95 capacities or dollar costs.

Failure regression matrix: no evidence→abstain; model mismatch→no compatible rows; forged citation→502; provider outage→503; reranker timeout→fusion fallback; revoked or deleted version→409/empty retrieval; foreign conversation→404. The current tests cover the listed cases unevenly; add full provider fault-injection, concurrent policy-change, index degradation, context-overflow, retry-storm, streaming disconnect and 100/1,000/10,000-user load tests before production acceptance. Streaming is not implemented, so disconnect tests are future work.
