# Parsing, layout and OCR

A digital PDF contains text drawing instructions that PyMuPDF can extract; a scanned PDF page may contain only an image. OCR recognizes visual glyphs and is therefore slower, language-dependent and error-prone. [The parser](../../apps/api/src/insightrag/ingestion/parsers.py) uses PyMuPDF page text blocks with `page:N:block:M` locators. An empty page invokes PyMuPDF's Tesseract-backed OCR only when `INSIGHTRAG_INGESTION_OCR_ENABLED` is true; otherwise the version fails. This avoids silently indexing an incomplete document. PDF block order can differ from human reading order; headings/tables are not reliably reconstructed from arbitrary PDFs. DOCX preserves paragraph/heading/table body order and `body:N`/`table:N` locators, not fabricated rendered page numbers. TXT uses UTF-8 line numbers. CSV/XLSX produce rows with a file/sheet row prefix and are routed to a structured table.

Docling adds document layout and table understanding at model/compute/dependency cost; pdfplumber offers layout-oriented PDF extraction; PyMuPDF is the smaller page/block/OCR integration chosen here. Unstructured offers a broader file-format framework but adds operational surface. No parser is universally best: evaluate on a labeled corpus for text coverage, reading order, table cell accuracy, heading F1, locator correctness and OCR character/word error rate. Count pages with zero text and compare extracted totals or key-value pairs to ground truth, but never use those extracted numbers as approved analytics without validation. A 2 GB PDF exceeds this phase's 50 MiB source limit; solving it requires multipart object upload, streaming/sandboxed page processing and memory/CPU quotas.

OOXML is a ZIP container. The [upload validator](../../apps/api/src/insightrag/security/uploads.py) rejects encrypted/nested/active archives, path traversal, extreme expansion, excessive members and malformed manifests before parsing. A clean antivirus verdict is necessary but not sufficient against parser exploits. Production should isolate parsers in no-network, low-privilege processes with CPU/RAM/temp-disk limits and patched libraries. Alternative OCR services require data-residency, retention, cost and confidentiality review. Monitor parse duration, expanded bytes, pages/rows, OCR rate, empty/low-confidence pages and user-reported citation quality.
